# full-stack-web-based-task-of-project-management-system-between-student-and-teacher-STU-TEACH


A full-stack web-based Task & Project Management System developed using **React** and **ASP.NET Core Web API**. The system helps teams efficiently plan, organize, track, and collaborate on projects through an intuitive interface and role-based access control.

Inspired by platforms such as **Trello** and **Asana**, this application provides essential project management features including task assignment, progress tracking, collaboration tools, and project analytics.

---

## 📖 Project Overview

This system is designed to improve productivity and collaboration for teams working on software development projects, academic assignments, or business operations.

Users can create multiple projects, assign tasks to team members, monitor project progress, and communicate through task-based comments.

---

## ✨ Features

### 👥 User & Team Management

* User registration and login
* Secure authentication
* Role-based access control

  * Admin
  * Project Manager
  * Contributor
* Assign users to project workspaces

### 📁 Project Management

* Create new projects
* Edit project information
* Archive completed projects
* Add and manage project members
* Define project goals and timelines

### ✅ Task & Subtask Management

* Create tasks and subtasks
* Assign tasks to team members
* Set task priority levels
* Configure due dates
* Upload file attachments
* Track task status:

  * To-Do
  * In Progress
  * Done

### 💬 Collaboration

* Task comment system
* Mention users within comments
* Improve team communication

### 📊 Dashboard & Analytics

* Personal dashboard

  * Upcoming tasks
  * Overdue tasks
* Project dashboard

  * Overall project progress
  * Task distribution
* Visual reports

  * Bar charts
  * Pie charts
  * Timeline visualization

## 🚀 Getting Started

### Prerequisites

* .NET SDK
* Node.js
* SQL Server
* Visual Studio or Visual Studio Code

### Backend Setup

```bash
cd Backend

dotnet restore

dotnet ef database update

dotnet run
```

### Frontend Setup

```bash
cd Frontend

npm install

npm start
```
